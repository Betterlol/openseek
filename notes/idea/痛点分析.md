
传统 AI Agent 实际遇到过一些痛点：
1. 跑 shell 命令场景：
    - 出于节省 `token` 的考虑，通常 Agent 倾向于无输出的执行 shell 命令，如果命令执行失败，Agent 需要重跑命令并自己定义截取输出的最后几行作为提示，这样可能会导致来回的执行，浪费时间和 token。其实可以定义统一的跑 shell 命令的接口，Agent 只需要调用这个接口，在执行成功时只返回结果，不成功时返回错误码和错误输出。（Result[Err, OK] 的感觉），同时尽量倾向于写文件，让 Agent 选择读文件的内容，这样就不需要在截取找不到原因后需要重跑命令的情况发生了！
