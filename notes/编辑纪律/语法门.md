在通过 *文件存在性检查*/*(edit 的 old_string 存在性检查)* 之后，进入 *预写入语法门 (moonc syncheck)*

*openseek/agent_tool/internal/auto_check/parse_gate.mbt*
- 1. content_parse_errors
```
content_parse_errors(path, content):
  │
  ├─ ① gate_scratch_name(path)  → 确定临时文件名
  │    .mbt    → parse_gate.mbt
  │    .mbt.md → parse_gate.mbt.md
  │    moon.mod → moon.mod
  │    moon.pkg → moon.pkg
  │    others  → None（跳过门控）
  │
  ├─ ② @fs.tmpdir(prefix="openseek-parse-gate-")
  │
  ├─ ③ @fs.write_file("{dir}/{scratch_name}", content, CreateOrTruncate)
  │
  ├─ ④ @async.with_timeout_opt(10s, () => {
  │      @shell.collect_shell_output(
  │        "moonc syncheck -error-format json {scratch_name}",
  │        cwd=dir, max_output_chars=200000
  │      )
  │    })
  │
  ├─ ⑤ decide_parse_gate(output) → ParseGate?
  │    ├─ 词法/语法错误 → Some({errors, truncated})
  │    ├─ 退出码 0 且无错误 → Some({errors: [], truncated: false})
  │    ├─ 输出截断且无错误捕获 → None（故障开放）
  │    └─ moonc 缺失（exit 127）或输出无法解析 → None（故障开放）
  │
  └─ ⑥ noraise: cleanup temp dir
```
> moonc syncheck 可以理解为 MoonBit 编译器提供的“语法检查 / 解析检查”命令。`moonc syncheck -error-format json {scratch_name}`
> 增量拦截：只有在你的编辑**引入**了新语法错误时才会被拦截
> `decide_parse_gate()` 提取其中的语法错误信息。

该门：
- write: 新内容有语法错误 → 拒绝写入
- edit: 新增语法错误 → 拒绝编辑     
- multi_edit: 任一文件有新增语法错误
  → 整个批次不写入
