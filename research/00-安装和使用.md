# OpenSeek 安装与使用指南

## CLI

### 1. 前置条件

- **MoonBit 工具链**（`moon`），stable 或 nightly 通道均可（CI 双通道验证）
- **`just`**（构建门），`jq`（仅 `just check` 需要）
- 网络访问 api.deepseek.com / api.moonshot.cn
- 可选：桌面端需要 `git submodule update --init desktop/lepus`

### 2. 安装（获取源码）

```sh
git clone https://github.com/bobzhang/openseek
cd openseek
git submodule update --init desktop/lepus   # 只跑集成门需要
```

> 提示：本仓库目前**没有发布到 mooncakes 的二进制包**，以源码方式使用。它同时是 monorepo（含桌面端与 editor），普通使用只需要根模块。

### 3. 快速上手（开发模式）

配置 API key 后直接跑（首次会自动拉取依赖）：

```bash
export DEEPSEEK=sk-...   # DeepSeek；用 Kimi 则 export KIMI=sk-...

# 一次性任务（headless，stdout 输出 JSONL 事件流）
moon run cmd/openseek -- run "检查这个项目并写一份简短总结"

# 指定模型（默认 deepseek-v4-pro）
OPENSEEK_MODEL=deepseek-v4-flash moon run cmd/openseek -- run "阅读文档"

# 交互式 TUI（默认模式）
moon run cmd/openseek -- tui
```

### 4. 编译成独立二进制（生产使用）

```sh
moon build cmd/openseek --target native --release
# 产物在 target/native/release/build/ 下，名为 openseek 或 openseek.exe
./target/native/release/build/openseek --help
```

把二进制放入 `PATH` 后即可直接 `openseek run "..."`、`openseek tui`。

### 5. 常用参数

| 参数/环境变量 | 说明 |
| --- | --- |
| `--model` / `OPENSEEK_MODEL` | deepseek-v4-flash / deepseek-v4-pro / kimi-k2.7-code / kimi-k2.7-code-highspeed |
| `--max-steps N` / `OPENSEEK_MAX_STEPS` | 步数上限；省略时以模型上下文窗口为界（自动 checkpoint 续跑） |
| `--dir` / `OPENSEEK_DIR` | 工作区目录（默认 `.`） |
| `--session <id>` | 恢复指定会话；每次运行默认生成 `cli-时间戳` 会话 |
| `--session-root` | 会话存储位置（默认 `.openseek/`） |
| `--no-session` | 临时会话（不持久化） |
| `--concurrency N` | best-of-N 并行（N 份工作区拷贝，不污染原目录） |
| `--thinking no\|high\|max` | 推理模式（默认 max） |
| `--api-url` / `OPENSEEK_API_URL` | 自定义端点 |
| `--system-prompt-file` | 自定义系统提示词 |

### 6. 会话管理（离线，无需 key）

```sh
moon run cmd/openseek -- sessions list                          # 列出可恢复会话
moon run cmd/openseek -- sessions show <id>                     # 查看会话
moon run cmd/openseek -- sessions compact <id> --file s.txt --from 1 --to 120   # 手动压缩
moon run cmd/openseek -- tui --continue                         # TUI 恢复最近会话
moon run cmd/openseek -- tui --session <id>                     # 恢复指定会话
```

### 7. 其他模式

```sh
moon run cmd/openseek -- review --base HEAD~1    # 只读代码审查（固定 V4Pro，忽略 --model）
moon run cmd/openseek -- mcp --mcp-config mcp.json   # 校验 MCP 配置（不发起会话）
moon run cmd/openseek -- serve                   # JSONL 命令服务器（TUI 内部用，也可自集成）

# 浏览器查看会话
just inspect                                     # 启动 viz 服务器，浏览器打开
```

### 8. 验证安装

```sh
moon run cmd/openseek -- --help          # 离线，无需 key
just check                                # 完整工程检查（较慢）
moon test cmd/openseek                    # 包测试
```

## GUI (APP)

打开：https://openseek-api.moonbitlang.cn/
下载桌面端 APP，但目前只支持 macOS，尚且不支持 Windows & Linux。
桌面端 SeekMoon 目前只正式发布了 macOS Apple Silicon 版本，且走官方自建 CDN（GitHub Releases 页面是空的）。


### 源码构建

#### 2. Windows（x64）

```powershell
# 手动逐步（脚本路径见下）
git submodule update --init desktop/lepus     # Git Bash 里跑更稳
cd desktop\lepus
moon install ./cli --bin target/lepus-tools
powershell -ExecutionPolicy Bypass -File scripts\install_webview2_headers.ps1   # 装 WebView2 COM 头
cd ..
moon build frontend/desktop --target js --release
Copy-Item ..\_build\js\release\build\openseek_desktop\frontend\desktop\desktop.js frontend.js
moon build . --target native --release
cd ..
moon build cmd/openseek --target native --release
```

**推荐直接走一键脚本**（自动完成以上全部 + 引擎构建）：

```powershell
moon -C desktop run --target native package/windows
# 优化产物：加 -- --release
# 只构建 bundle+zip、跳过 NSIS：-- --target zip
```

- 产物：`desktop/dist/windows-x64/SeekMoon/`（bundle）、`dist/SeekMoon-windows-x64.zip`、`dist/SeekMoon-Setup.exe`（NSIS 安装器，装到 `%LOCALAPPDATA%\Programs\SeekMoon`，无需管理员）
- 装 NSIS 装器需 `makensis.exe` 在 PATH（或解压到 `desktop/dist/tools/nsis-3.12/`）
- **目标机需装 Microsoft WebView2 Runtime**
- 链接器风格自动探测（clang/msvc/mingw），可用 `OPENSEEK_DESKTOP_LINK_STYLE` 覆盖

#### 3. Linux（x86_64）

```sh
# Debian/Ubuntu: sudo apt install pkg-config libgtk-3-dev libwebkit2gtk-4.1-dev curl
# Arch:           sudo pacman -S gtk3 webkit2gtk-4.1 curl

moon -C desktop run --target native package/linux            # debug
moon -C desktop run --target native package/linux -- --release
```

- 产物：`dist/SeekMoon-linux-x86_64.AppImage`（捆绑引擎+前端+工具链 seed）
- **运行机器仍需系统 GTK3 + libwebkit2gtk-4.1**；无 FUSE2 时用 `APPIMAGE_EXTRACT_AND_RUN=1` 运行

#### 4. 构建后运行与数据

- 开发模式：`moon run ./desktop/package/dev`（从仓库根）；浏览器调试页：`desktop-dev.html`
- 打包 app 开箱即用：默认走 `openseek-api.moonbitlang.cn` 代理端点，**无需 API key**；设置里可切 BYOK
- 会话在 `~/.openseek`，与 CLI/TUI 互通；工作区在 `Documents/OpenSeek/<session-id>`
- 验证构建门：`just check` / `just test`（全 workspace，含桌面端）
